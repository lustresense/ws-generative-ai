## Struktur Folder

```text
tugas-1/
|- README.md
|- module-01/
|  |- src/
|  `- output/
|- module-02/
|  |- src/
|  `- output/

|  |- src/
|  `- output/
|- module-04/
|  |- src/
|  |- data/
|  `- output/
`- module-05/
   |- src/
   |- data/

```

Setiap folder `src/` berisi source code materi dan exercise. Folder `output/` berisi hasil eksekusi atau screenshot output. Module 04 dan Module 05 juga memakai folder `data/` untuk file JSON, CSV, dan TXT.

Module 03 memiliki package helper di dalam `src/` untuk latihan Modules and Packages serta exercise package structure.

## Menjalankan Source

Jalankan dari root repository:

```powershell
python ./tugas-1/module-01/src/1_2a_variables_data_types.py
```

Atau masuk ke folder source module terkait lalu jalankan file Python-nya:

```powershell
cd ./tugas-1/module-02/src
python .\2_1_lists.py
```

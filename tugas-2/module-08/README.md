# Module 08 — Embeddings & Semantic Search

Materi: OpenAI-SDK-compatible embeddings via Gemini, Voyage embeddings, cosine similarity, semantic search/vector store, chunking, retrieval evaluation, metadata filtering, dan 4 exercises.

PDF menggunakan OpenAI `text-embedding-3-small` dan Voyage `voyage-3`. Environment tugas ini menggunakan Gemini `gemini-embedding-2` untuk pipeline embedding utama dan Voyage `voyage-4-lite` untuk contoh Voyage.

Output screenshot untuk setiap source diletakkan pada folder `output/` dengan nama yang sama seperti source (`.py` → `.png`).
